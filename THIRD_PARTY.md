# Included third-party components

- Three.js r180: exact core/renderer modules from the supplied v2.7.0 release.
  MIT notice: `public/licenses/three.txt`.
- Supabase JavaScript SDK and bundled components: exact account module from the
  supplied v2.7.0 release. MIT notice: `public/licenses/supabase.txt`.
- Manrope and Space Grotesk fonts: SIL Open Font License notices under
  `public/licenses/`.
- Build/test dependencies are pinned in `package-lock.json` and carry their own
  license files in installed npm packages.

The new aircraft, spacecraft, cockpit, orbital scene and procedural textures
are generated by this project's source. No external aircraft models or film
audio were downloaded. The X-wing and TIE fighter names/design references are
used for the requested Star Wars fan mode; this project is not an official game.
